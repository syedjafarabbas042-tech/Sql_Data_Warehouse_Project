A modern **Data Warehouse built using SQL Server**, covering ETL processes, data cleaning, data modeling, and analytics.

## 📌 Project Overview

This project follows a **Medallion Architecture**:

**Bronze → Silver → Gold**

* **Bronze:** Raw data ingestion
* **Silver:** Data cleaning and transformation
* **Gold:** Business-ready data for analytics

## 🛠️ Technologies

* SQL Server
* T-SQL
* SSMS
* Git & GitHub

## 🔄 ETL Process

The project demonstrates:

**Extract → Transform → Load**

including data integration, cleaning, transformation, and validation.

## 📊 Data Modeling

The Gold layer uses **dimensional modeling** with fact and dimension tables to support analytical queries and reporting.

## 🎯 Goals

* Learn real-world Data Warehouse architecture
* Practice SQL Server and advanced SQL
* Understand ETL and data transformation
* Build analytics-ready datasets
